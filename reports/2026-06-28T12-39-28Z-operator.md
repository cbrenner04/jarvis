## Workflow / harness observations

- **Actuator scope-creep (#739).** The codex actuator added an out-of-scope
  ready-gate `node_modules` bootstrap (`bun install --frozen-lockfile` in
  `runReadyAndCommit`) to work around a biome-binary-not-found error it hit in
  its own gate. The review verdict flagged it; the actuator reverted the *code*
  but left incoherent residue: a docstring claiming "install-if-missing", a
  `run-loop.md` paragraph documenting the phantom bootstrap, and a
  **wrongly-deleted** `ready-gate` test. Operator recovered by reverting all
  three to `main` and finalizing the gate in isolation. Related to the existing
  `verdict-survives-actuator-overreach` seed.
- **Cursor idle-stall is terminal (#747).** codex was fully quota-exhausted, so
  every patch attempt cascaded to cursor, which produced **zero output** and
  tripped the 600s idle watchdog — twice. Because an idle-timeout doesn't advance
  the cascade, the run died at exit 8 each time while `claude` sat available.
  This is exactly the **`watchdog-idle-timeout-advances-cascade`** seed (already
  filed). Operator workaround: reordered `modes.patch.agentOrder` to put claude
  ahead of cursor so the run reached a healthy rung. Cursor itself is not broken
  (it serves the owner's intent runs fine) — the failure is the
  cascade-on-idle gap plus zero-output startup hangs as a post-codex fallback.
- **Contention gate-timeouts (both impls).** Both impl runs blew the 600s ready
  deadline (exit 124) and stayed draft despite `criteria-complete`. Two leaked
  `*-hang.sh` test fixtures were busy-looping at ~100% CPU (see below). Operator
  finalized both gates in isolation — clean exit 0 — confirming contention
  flakes, not bad code.
- **Leaked + spinning test fixtures.** Two watchdog/idle helper scripts
  (`idle-hang.sh`, `agent-only-hang.sh`) were orphaned from earlier killed runs
  and pinning a core each for hours — they busy-loop instead of sleeping and
  leak on abnormal exit. Seeded as **#748**. The auto-mode classifier blocked the
  operator from killing non-self-spawned processes, so reaping required the human.
