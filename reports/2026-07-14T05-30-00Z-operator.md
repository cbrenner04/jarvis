## The headline finding

**A v2 implement run's agent commits code that does not compile, and nothing tells it.**

Four of six implement runs committed a tree that failed `typecheck` or `check`. The now-full-tier
gate (#1539) **caught every one** — that part works, and it is the session's most valuable
outcome. But a red gate is *terminal*: the run stops at `ready_finalize_failed`, publishes a draft
PR over the broken commit, and the operator repairs it by hand. On #1539 and #1540 the repair was
`bun run fix`. On #1542 and #1544 it is real work, so both are parked.

The write loop had the worktree open, the agent in context, and the gate's stderr in hand — and
threw all three away. Seed: **`red-gate-does-not-feed-back-to-the-agent`** (#1543). This is now
the highest-value v2 fix: without it, every implement run is a coin flip the operator settles by
hand, and *the better the gate gets, the more often that happens*.

## What worked

- **Split and plan are reliable.** 12 `intent-reviewed` runs → 10 clean; 13 `plan` runs → 9 clean.
  The four blocked plans were *legitimate* dependency blocks (each waiting on a sibling's
  implementation), not defects.
- **The P0 `criteria-ticked` contract earned its keep.** #1542's re-run went
  `blocked / contract_miss` rather than falsely reporting done. It is doing exactly the job it was
  built for.
- **The P0 session's `run wait` rule held.** Checking `run list` for a live row on the same branch
  before concluding a run dropped its work was correct every time; the terminal-id trap never bit.

## Operator notes

- **Concurrency is the enemy of the gate.** Three concurrent implement runs put three `bun run
  ready` processes on one machine; the full suite has a 600 s deadline and a hand-run gate hit it
  (exit 124) under that load. Keep implement runs to ~2.
- **The daemon still goes deaf.** With runs live, `jarvis run log <id>` hung past 2 minutes,
  twice. The durable state (`~/.jarvis/state/v2.sqlite`, `attempts` table) was the only reliable
  way to see what a run was doing.
