# Operator session report — 2026-07-24 (P0–P2)

Drove the P0–P2 block from `.scratch/2026-07-24-spec-priorities.md`. **All of P0 and
P1 landed; P2 has one item (TUI window) untouched.** The session's real story is
that two infrastructure defects — a non-WAL state store and a blind idle watchdog —
were silently corrupting nearly every run, and fixing them unblocked the backlog.

Cost: **$117.30** operator API only (claude-opus-4-8; agent runs on subscription).
API time 1h 22m; wall 5h 47m. Two operators ran concurrently for much of the session.

## Headline outcomes

- **P0 #1 role-stalled → #2095.** `role_stalled` settled non-retryable/stop, discarding a
  *committed* write step. Fixed so post-commit stall settles like post-commit timeout
  (resumable/retryable), pinned by a pure `isPostCommitReviewRetryableFailureKind` predicate.
  Review is now fully reliable.
- **P0 #2 query-limit-cap → #2091.** Stranded 9 times. Root cause was never a spec defect: the
  mutation gate kept landing on a *different* newly-restructured comparison each attempt. Amended the
  AC (#2073) to require the filter predicate be a **pure exported function** unit-tested directly —
  gave the gate a stable target, landed first try after.
- **P1 #3 run-log-and-wait → #2101.** `run log`/`run wait` now resolve across live keyed daemons
  (union + `isLive` preference), fixing the digest-rotation blindness that bit this session repeatedly.
- **P1 #4 dimension-filters → #2110.** `--project/--branch/--spec/--status` on the filtered path.
- **Keystone: WAL state store → #2081.** The store opened SQLite bare (`journal_mode=delete`,
  `busy_timeout=0`), so any concurrent writer *or reader* (a `run list` poll, a TUI tick) could throw
  `database is locked` and discard a completed write step. Verified live: `journal_mode=wal` now.
- **Cursor watchdog → #2088.** Root cause of every `role_stalled`: cursor spawned with
  `--output-format text` buffers all output, so the silently-editing review actuator hit the 90s idle
  budget at exactly 90003ms every time. Telemetry proved it (debate roles stream a verdict → complete;
  only the actuator stalled). Switched cursor to `stream-json --stream-partial-output` + an NDJSON
  reader. Codex verified unaffected (570 invocations, 0 stalls); opencode isn't wired in v2.
