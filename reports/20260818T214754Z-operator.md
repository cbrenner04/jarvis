## Findings / friction

1. **`--base origin/main` + stale local ref → broken publications.** `gh pr merge` advances origin/main on the *remote*; the local tracking ref only updates on `git fetch`. Launching implements with a stale `--base origin/main` gave stale bases (out-of-scope diffs) and branches tracking `origin/main` that broke the completion step's bare `git push` (`push.default` unset→simple). Fixes: repo-local `git config push.default current` (reversible), and `git fetch origin main` before every launch. **Seeded** `harness-publication-push-uses-explicit-refspec` (publication should push `git push origin HEAD:<branch>`).
2. **Daemon died mid-session under parallel load** (no `daemon.log`), orphaning a completion step that stayed `in-progress` and un-killable (socket ENOENT). Restarted; the orphaned row persists as clutter. Covered by existing `operator-terminates-stale-nonactive-runs` (bumped in re-prioritization).
