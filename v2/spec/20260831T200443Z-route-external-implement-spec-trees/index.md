# Route external implement spec trees

Admitted external plan indexes (`~/.jarvis/specs/<safeId>/plans/<name>/index.md`) still route linked subspecs, prompt injection, criteria re-reads, index ticks, review/shrink context, and Git publication through the materialized code worktree, so in-place external trees cannot drive implement execution.

Ordered: `00` pins external routing roots and active subspec selection; `01` wires write-loop artifact/criteria paths and adapter read access; `02` completes external linked passes (pinned re-read, index tick, multi-link advance); `03` gives review and shrink read-only external spec context; `04` excludes external spec bytes from Git surfaces; `05` documents the landed boundary.
