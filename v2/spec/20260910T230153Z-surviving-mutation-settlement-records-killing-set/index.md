# Record the killing set and its observed result on a surviving-mutation settlement

A `surviving_mutation_failed` settlement names only the mutation site, so falsifying it means re-deriving the killing set by hand. Carry the resolved killing test paths the verifier actually ran, and that set's observed result, from the verifier through the settlement to the run record and operator error.
