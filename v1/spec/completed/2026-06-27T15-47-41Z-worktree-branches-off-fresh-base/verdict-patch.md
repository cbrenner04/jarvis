This must lock in the spec’s stated fallback rule: fallback is based on ref resolution, not fetch success. The completed spec and acceptance criteria apply that fallback behavior to both affected creation sites, but the current suite pins fallback only through `ensureWorktree`, leaving the managed path’s fallback behavior unverified.
