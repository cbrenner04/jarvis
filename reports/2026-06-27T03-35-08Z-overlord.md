## Observations (what bit, what worked)

1. **Lint-dirty emitters poison run gates.** Plan/intent emit spec markdown with
   `MD012`/`MD018`/`MD038` violations; the run's full-tree `lint:md` then fails on
   *its own* emitted index/subspec, unrelated to the code change. Cost hours of
   un-poisoning `main` by hand. Root fix is seeded (`plan-generated-...`,
   `intent-emit-lint-md-clean`); until it lands, every run can wedge on it.
2. **Never admin-merge before green CI.** Admin-merging draft/non-green plan+intent
   PRs put lint-dirty markdown on `main` and poisoned every subsequent gate.
   Corrected mid-session. Note: `gh pr checks` sometimes reports "no checks" while
   CI actually ran — verify via `gh run list --branch`.
3. **Concurrent fan-out has a stale-base tax.** ~10 concurrent runs branch off one
   `main`; each lands needing an integration-merge + conflict resolution (esp. the
   shared `v1-behaviors.md` and any index.md a recovery PR touched).
4. **A claude-first fan-out self-throttles its own claude quota** (not another
   operator). Fine if the work is useful; don't reconfigure to avoid it.
5. **Load-flaky tests gate-poison under contention** — spawn-classification
   (deflaked, #584), the watchdog `last_output_age_ms` test (seeded), and #601's
   review tests (real bug: the verdict actuator spawned the real `claude` binary
   in a test that only injected `codex` → EPIPE in CI, green locally; fixed by
   mocking the actuator).
6. **The actuator floor was over-engineered + mis-scoped.** `actuationCapabilityFloor`
   filters the patch impl loop (`buildActiveAgents`), not the verdict actuators —
   it floored haiku off ordinary patches. The real lever is the
   `subRoleAgentOrder.reviewActuator` override. Removed from config; rip-out seeded.
7. **`jarvis cleanup` pushes spec-archive commits directly to `main`** — bypasses
   PR review; surfaced at close-out (operator handled `main`).
8. **#520's three re-run-hygiene intents were all stale** (already-shipped via
   auto-reset, or mis-scoped). The plan stage correctly blocked them rather than
   author no-op specs.
