# Plan Review Subtractive Mandate

repo: cbrenner04/jarvis

The plan loop only ever adds: refine appends, draft expands, review rewrites "to
address the most important issues" — and review, the one phase that could shrink a
spec, is given a purely additive mandate. The decisions-ledger fragment fixed the
*shape* of authored content; this fixes the *direction* of review. Make a review
pass a compressor: prefer cutting, never grow the spec except to add a genuinely
missing decision/criterion/doc, cut prose and never decisions.
