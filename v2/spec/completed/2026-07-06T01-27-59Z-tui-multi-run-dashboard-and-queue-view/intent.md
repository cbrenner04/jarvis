# Tui Multi Run Dashboard And Queue View

# TUI multi-run dashboard and queue view

The TUI shows a dashboard listing all in-progress runs at once, with queued
runs surfaced in a distinct queue view showing their admission-pending state.

## Prerequisites

- Memory-watermark admission and `queued` status exist
- Concurrent run execution is implemented
