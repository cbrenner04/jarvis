## Findings the mutation gate + plan loop surfaced

**Two plans blocked on real contradictions, both retargeted rather than forced:**

- `keyed-daemons-coexist` (→ #1978): its observation-scoping AC was mutually exclusive with its
  fixed-socket regression AC, because run state is keyed by `JARVIS_HOME`, not digest. Implementing
  scoping would stamp rows with the admitting daemon's digest and hide a restarted daemon's own
  reconciled rows. Narrowed to path-disjointness + a docs correction.
- `write-step-cascades-on-quota` (→ #1981): telemetry for the observed run showed `exit_kind: ok` on
  codex — the agent exited 0 after its own usage limit, and only the claude classifier detects that
  envelope. Retargeted at `shared/invocation/agents.ts`.

**Spec size is a first-class failure mode — confirmed twice more.** Two multi-subspec specs
(`write-step-reports-uncovered-changed-lines`, `retire-superseded-daemon-when-idle`) each stalled
`contract_miss` repeatedly: the run completed subspec 00, ticked the index, routed to 01 in the same
run, exhausted its budget, and stranded — discarding 00 every time. Splitting each into separate
specs (#2002, #2011) landed both. Same lesson as the prior session's three-way keyed-daemon split.
