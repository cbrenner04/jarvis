## What went sideways (and how it was handled)

- **Pipeline implement shipped a production no-op; a subagent review caught it.** Both cursor and claude implemented correct guarded logic + valid `@mutate`s + a green gate, but the daemon's `pipelineExecutionDeps()` never *constructed* the `intentStaleReset` bundle, so the preflight never fired in a real run — the tests passed only because they injected the bundle directly. Hand-wired the real construction (lazy per-preflight `connectClient` against the daemon's own socket, threaded `daemonSocketPath` through `RunControlHandlerDeps`) plus a regression test through the real deps builder. A 3-lens adversarial **review-debate** (operator-requested) then cleared deadlock/leak/destruction and surfaced two robustness fixes applied before merge: self-connect failure now **fails open** (skip preflight, proceed) instead of hard-failing a healthy stage, and the self-RPC read is **bounded**. Never merge an implement on a green gate alone — the gate is not evidence the code runs.
- **The cognitive-complexity gate hand-blocked both agents, deterministically.** Adding the stale-reset branch pushed `advanceWorkflowStage` and `runAuthoredStages` over Biome's max-24 (both clean on main), and `biome check --write` cannot repair it → `iteration_commit_failed`. This is agent-independent (cursor 27/26, claude 25/26); the sanctioned fix is `// biome-ignore` on the orchestration functions. Recurs across sessions.
- **Cursor emitted structurally-invalid `@mutate` directives** on the pipeline (no path prefix, no `-> "<replacement>"`); claude's were valid. Combined with the deterministic complexity wall (clean on main → a tighter impl avoids it), that was a clear "claude if needed" case — re-ran the pipeline implement claude-first.
- **The mutation-checkpoint linker requires the criterion to name its enclosing test verbatim** (`linkDirectivesToCriterion`). Three plans this session would have hand-blocked on it (the recurring `mutation-checkpoint-criterion-must-name-enclosing-test` gap); pre-fixed each criterion at plan time to embed the exact `test()` title (prescribing titles for not-yet-written tests). All three implements then passed `spec.criteria-ticked`.
- **GitHub Actions hosted-runner outage.** #2644 failed CI three times with "job was not acquired by Runner of type hosted" (no tests ran); #2645–#2647 got no checks scheduled. Confirmed with the operator. Merged the last four PRs on full-local-ready (all suites + `lint:md` green locally) per operator approval — flagged the macOS-vs-Linux platform gap for the daemon change.
- **The corpus reflow degraded one malformed table.** A reflow-safety subagent verified all 107 reflowed files (code blocks byte-identical, tables/frontmatter/lists preserved) and found exactly one corruption: `v2/docs/write-behavior.md` had 4 CLI rows the author intended as a table but with no delimiter row and no blank line, so markdown-it parsed them as a paragraph and reflow joined them. Root cause is malformed source; fixed by moving the rows into the real table.
