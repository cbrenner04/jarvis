## The meta-lesson (seed #1706)

The manual mutation review the operator ran on every implement PR **is the harness gap**. A green gate
certified six straight cleanup no-ops; only mutation testing — break the production code, confirm a
test goes red — caught them. #1706 proposes an adversarial verification step in the implement workflow
(diff-derived guard mutations + a runtime smoke) gating the flip to `completed`. If it ships, the
hand-review tax disappears and `completed` means the code works.

## Findings

- **Mutation review earned its keep, repeatedly.** It caught all six cleanup no-ops and one untested
  hop in pr-body; it also cleared triage #1707 cleanly (5/5 mutations bite). It is the only thing that
  made "merged" mean "works" this session.
- **Publication is intermittently flaky** (`completion_commit_failed`, #1683). Two codex intents
  failed publication and were hand-published; the triage plan/implement published cleanly. **Not** a
  systematic daemon-auth break (ssh + gh auth both verified working) — transient network on the `gh`
  path, error swallowed into a vague status. Don't restart the daemon to "fix" it.
- **Never restart the daemon from inside the agent sandbox, or while a run is live.** Doing so cost a
  `kill -9` recovery (refused stop on active runs) and triggered the `.claude`-only husk bug (#1700):
  the daemon's own `git worktree add` failed silently and left a husk that poisoned retries. Fix:
  pre-create the worktree by hand (`git worktree add -b <branch> main`) before relaunch.
- **The daemon runs a stale code snapshot.** A commit-subject fix (#1695) looked broken until the
  daemon bounced from an up-to-date checkout — the operator's earlier bounce happened while the
  primary checkout was 4 commits behind, so it snapshotted pre-#1695 code.
- **Promotion-consumes-input works** — later intents deleted their own source seeds, one session after
  the fix landed.

## Corrections — mine

- **I misdiagnosed the publication flakiness as a daemon-auth break I caused** by restarting from the

- **I stacked redundant `until … grep` poll loops** several times and gave content-free "still

  whole workflow across run ids) is worth a seed.
