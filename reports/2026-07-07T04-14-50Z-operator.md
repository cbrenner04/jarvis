## CI-flake root-cause (major detour, fully resolved)

The recurring `Test (v2)` re-run tax was root-caused and killed:

- **Two real correctness bugs found + fixed**: `ipc/client.ts` never rejected a parked `nextFrame()` on socket close; `IpcServer.close()` self-deadlocked (forced socket-drain nested inside `net.Server.close`'s callback, unreachable while a socket is open — now concurrent).
- **The actual staller**: a leaked-handle test worker that never exits → 300s SIGKILL, unnamed. Structural fix: **agent-mode test runners now run per-file with a named per-file timeout** in *both* `run-v2-tests.ts` and `run-tests.ts`, so a hang is bounded, named, and can't wedge the whole run. One `Test (full)` run hung ~96 min before this landed; now the worst case is a named per-file timeout.
- The instrumentation then **named the residual staller**: `daemon-wait-run-completion.test.ts` (seeded as `daemon-wait-run-completion-test-leaked-handle`).
