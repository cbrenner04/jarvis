   on `main`, reddening every subsequent run's completion gate. Fixed by an
   autofix PR (#650). Already tracked by `merge-on-green-gate` +

## Recovery patterns that worked

- **Integration-merge-then-isolated-gate** for runs that branched off poisoned/old
  main: merge `main` into the worktree, `bun run ready` in isolation → green = the
  earlier red was poison/contention, not bad code. Used on #648, #649, #652-area,
  #651, #659, #660, #661.
- **From-scratch re-implementation** beat review-feedback for #520 source-spec-reset:
  a subtle post-completion async leak in the codex build survived 3 review-feedback
  rounds (round 3 made no changes) and a no-op fresh run; abandoning the branch and
  re-running so **claude** implemented it from scratch passed CI first try.
- **Contention discipline:** the known `watchdog last_output_age_ms` load-flake
  (unimplemented `deflake-watchdog` seed) red-gated a run under 3-way concurrency;
  isolated re-run was green.
