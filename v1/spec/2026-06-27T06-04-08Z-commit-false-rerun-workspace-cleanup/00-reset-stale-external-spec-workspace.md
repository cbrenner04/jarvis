# 00 - Reset stale external-spec workspace

External specs from `plan.commit:false` can be re-run before the prior patch run completes. Today the source spec auto-resets stale checklist/blocker edits, but the patch worktree, branch, and draft PR can remain and collide with the fresh attempt.

## Decisions

- On re-run of an incomplete external spec, close any open draft PR for the stale implementation branch, then remove the stale worktree and branch before creating a fresh worktree; rules out reusing the old branch and preserving stale commits.
- Cleanup is limited to external Jarvis-owned specs whose source spec still has unchecked automated acceptance criteria; rules out deleting normal in-repo implementation branches on ordinary resume.
- If any cleanup step cannot be proven successful, abort before agent invocation; rules out running against partially reset workspace state.

## Tasks

- Detect the external no-commit spec re-run case before patch worktree creation.
- Close the matching stale draft PR when one exists.
- Remove the matching stale worktree and local branch, then create a fresh worktree/branch for the new attempt.
- Preserve existing source-spec delta reset behavior.
- Add coverage for stale PR/worktree/branch cleanup and cleanup failure.
- Update durable docs in `v1/docs/operator-runbook.md` and `v2/docs/v1-behaviors.md`.

## Acceptance criteria

- [ ] Re-running an incomplete external spec generated by `plan.commit:false` closes the stale draft PR for that spec branch, removes the stale `.worktree/<spec-name>/`, deletes the stale local branch, and starts the next agent attempt in a freshly created worktree/branch.
- [ ] The same re-run still resets prior-attempt checklist ticks and appended `## Blocker` text before invoking the agent.
- [ ] If closing the stale draft PR or removing stale git state fails, `jarvis1 run` exits before invoking any agent and reports the failed cleanup step.
- [ ] Ordinary in-repo spec re-runs keep the existing resume behavior: an existing worktree/branch is reused rather than auto-deleted.
- [ ] `bun run typecheck` passes.
- [ ] `bun run test` passes.
- [ ] `v1/docs/operator-runbook.md` documents the no-commit re-run cleanup of checklist/blocker mutations plus stale worktree, branch, and draft PR state.
- [ ] `v2/docs/v1-behaviors.md` records the updated v1 behavior for external no-commit spec re-runs.
