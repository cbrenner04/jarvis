# Spec `repo:` Accepts Registered Project Keys

Make `jarvis run` accept a bare registered project key in a spec's `repo:` line, so that no-commit specs generated by `jarvis plan` against registered projects without an `origin` (typically non-git directories) resolve successfully instead of failing with `unrecognized \`repo:\` value: <key>`.
