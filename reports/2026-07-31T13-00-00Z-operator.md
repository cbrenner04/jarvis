It hit **six** implement runs this session; four needed a hand-fix.

## What cost the most, and why

**Review caught something real in 8 of 11 implement PRs.** A green ready gate was not sufficient evidence in any of these cases:

- a **destructive, non-transactional migration** (#2374) — `DROP TABLE` + rename with the
  `_migrations` row stamped afterward. A crash mid-migration would have destroyed every
  pipeline stage row *and* left the store unopenable, since the earlier `CREATE` is already
  stamped and never re-runs.
- a **module global written on every `contract_miss`** in the daemon hot path (#2370) — shared
  state clobbered across concurrent runs, and it made one assertion a same-expression compare.
- a **silent coverage loss** (#2412) — recovery regressions were *converted* rather than added
  to, so a fence layer went unguarded on every recovery path. Test count went **up**, so the
  loss was invisible by count. A mutation killed 4 tests on `main` and only 1 on the branch.
- **inversion theater** (#2406) — four "guard inversion" tests asserting against
  locally-defined helpers instead of production; one stayed **green** under a real mutation.
  Plus two production exports named to slip past the new static guard.
- a hardcoded `machineProfile: "home"` (#2363) that would have ignored the configured profile.

Every fix was verified by running the mutation and confirming the failure, not by trusting a comment checkpoint.

## Friction (not seeded)

- **The `(Manual)` marker is trailing-anchored** but plan agents write it leading, and the
  parse reads only the criterion's first line. This stranded **five** runs at `contract_miss`
  on criteria the agent could not satisfy. Seeded as #2394 (widened); it is the highest-value
  open item.
- **Serial dependency chains cost wall-clock.** Eleven plan runs settled `blocked` naming an
  unshipped sibling — correct behaviour, but it means fanning plans out only works across
  intents with no shared prerequisite.
- **`idle_output_timeout` on trivial changes.** Three runs died this way on work as small as a
  three-line deletion. Hand-finished each time.
- **`--reset-despite-dirty` destroyed a pushed commit.** Operator error: passing it on an
  incomplete spec retires the branch, remote included. Recovered the commit from
  `git fsck --lost-found`. This is the same hazard as the `iteration-timeout` seed.
- **A red check was admin-merged** (#2417), briefly reddening `main`. Fixed in #2418. The
  underlying cause is real and worth knowing: **ink never paints to a fake stdout on the CI
  runner**, so a test asserting painted output cannot pass there — the known
  `tui-tests-bypass-the-render-path` constraint. My first two diagnoses (flush races) were
  wrong; the fix moves the proof to the injected input hook and production monitor state.
